# Mini Maps — Telegram Mini App

Карта на данных OpenStreetMap в виде Telegram Mini App: поиск, маршруты (авто, вело, пешком), избранное, импорт GPX, офлайн-кэш плиток.

Весь код в одном файле — `index.html`, сборка не нужна.

## Запуск
1. Выложите репозиторий на HTTPS-хостинг (GitHub Pages, Vercel, Netlify).
2. В @BotFather создайте Mini App (`/newapp`) или задайте Menu Button со ссылкой на сайт.

## Сервисы
- Плитки: OpenStreetMap, OpenTopoMap, CyclOSM
- Поиск: Nominatim
- Маршруты: routing.openstreetmap.de

Публичные сервисы OSM подходят для старта; для нагрузки перейдите на свои серверы или платные API.
